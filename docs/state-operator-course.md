# Noisy state-only operator course

The core producer `src/state-operator-course.mjs` provides independent simulations for Worldlaw's trajectory learner. It imports no Worldlaw fitting, expression-evaluation or integration code. The old exact-derivative course remains a distinct regression test.

## Fixed scope and split

The development roster contains four laws. The evaluation roster contains twelve nonlinear scalar second-order ODE laws and eight scalar periodic semidiscrete PDE laws. Their coefficient scale is generated by a fixed seed, and fitting, selection, additional-experiment and test recordings use distinct initial conditions, forcing histories and noise seeds. This is a synthetic twenty-law course with withheld recordings and parameters, not a claim of twenty independently measured mechanisms or externally blind family discovery.

All equations are dimensionless. There are 401 observation times per recording. ODEs use a step of 0.02; fields use 0.01 on 32 periodic sites with spacing 0.25. The simulator uses explicit midpoint integration with 24 internal steps per observation. An independent exact discrete Fourier solution checks the heat equation and the expected second-order refinement. This finite difference course does not certify continuum mesh convergence for every nonlinear equation.

Observation noise is independent Gaussian noise per state channel at 40, 25 or 15 dB relative to that recording's clean channel RMS. Sensor noise therefore varies with the recording's signal amplitude; comparisons must retain that convention and cannot equate increased drive amplitude with a fixed-noise experiment.

## Learning boundary

`observeStateOperatorWorld` returns two separate objects. Only `observation` enters the learner: recording identity, geometry, spacing, sample time, noisy state vector and commanded input. There are no exact time derivatives, clean states, governing equations or exact initial states in that object. The `reference` object is reserved for scoring. A forecast may initialize from an explicitly charged prefix of noisy observations; it must never reset from later states.

The experiment budget is two initial training recordings, one whole model-selection recording, one additional recording and one independent final test. Active and random methods receive the same admissible three-plan menu and one additional query. A failed or refused choice still consumes the query allocation; the receiver declares its fallback and retains failures in the denominator. Model-selection recordings are consumed evidence, not held-out evaluation.

## Negative mechanisms

The omitted-mechanism roster simulates an actual delayed oscillator with retained history; a three-state Lorenz system observed only through position and its first derivative; an antipodal nonlocal field coupling; and third-order dispersion. Hidden internal state and history never enter observation records. Nonlocal and dispersive fields contain a third spatial mode so a two-mode local surrogate is insufficient by construction.

The receiver additionally permutes complete state vectors in time while keeping timestamps and command histories fixed. It must report accepted predictive candidates for these controls, even when inconvenient. A residual screen is not a calibrated structural identification guarantee, and a predictor that makes no structural claim cannot be credited with proving zero false structural identification.

## Reproduction

```sh
node --test test/state-operator-course.test.mjs
node src/state-operator-course.mjs development > development-observations.json
```

The matched learner comparison belongs to Worldlaw's maintained receiving script and pins this source commit. Exact sample arrays, models, free forecasts, failed solves and complete denominators are retained there.
